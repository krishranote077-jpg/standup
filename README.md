# The Velvet Mic - Comedy Club & Open Mic Manager 🎙️

A modern, full-featured web application for standup comedy clubs, open mic nights, and stage management.

Live demo / direct entry: [index.html](index.html)

---

## 🌟 Key Features

* **⏱️ Backstage & Stage Timer**:
  * Visual 5-minute countdown with stage light indicators (Green = Clear, Amber = 1-min warning, Red = Overtime).
  * WebAudio synthesized sound cues (bell chime and overtime buzzer).
  * Fullscreen teleprompter mode for on-stage comedians.

* **🎤 Comedian Booking Portal**:
  * Interactive 5-minute slot selector.
  * Real-time slot reservation with stage names, genres, and audio/mic notes.
  * Self-service booking cancellation / management with passcode.

* **🎟️ Audience & Seating Capacity Tracker**:
  * Real-time club basement capacity tracker (VIP Front Tables, General Seating, Standing Room Bar).
  * Digital club ticket pass generation with simulated QR code and printable passes.

* **📊 Host / Producer Dashboard**:
  * Live metrics: total performers, audience capacity percentage, show runtime, and open slots.
  * Lineup master controller with stage calling and completion status.
  * Export lineup and reservations as CSV or JSON.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it via GitHub Pages. No backend or build step required!

### GitHub Pages Setup
1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
3. Click **Save**. Your site will be live within seconds!
